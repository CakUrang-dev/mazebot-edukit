Skematik & Rangkaian Pinout ESP32

Desain minimalis, hemat biaya — ESP32 DevKit V1 mendorong 3× Ultrasonik + Line Follower + Dual Motor DRV8833 dalam satu PCB kompak:

// Pinout Aktuator DRV8833
• Motor Kiri (IN1, IN2) : GPIO 18, GPIO 19 (PWM)
• Motor Kanan (IN3, IN4) : GPIO 21, GPIO 22 (PWM)

// Pinout Sensor Jarak HC-SR04 (3x)
• Ultrasonik Kiri : Trig = 13, Echo = 34
• Ultrasonik Depan : Trig = 12, Echo = 35
• Ultrasonik Kanan : Trig = 14, Echo = 32

// Sensor Garis Finish TCRT5000
• Digital Out (DO) : GPIO 27 (Active LOW/HIGH)
